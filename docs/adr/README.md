# Architecture decision records (ADRs)

This directory records the significant architecture decisions for the National
Triage Standards website. The format follows the NHS England
[repository-template ADR convention](https://github.com/nhs-england-tools/repository-template/tree/main/docs/adr).

| [ADR-002](ADR-002_Rebuild_clean_rather_than_fork_DPSP.md) | Rebuild clean rather than fork DPSP | Accepted |
| [ADR-003](ADR-003_New_repository_with_clean_history.md) | New repository with clean history | Accepted |
| [ADR-004](ADR-004_Private_repository_with_published_GitHub_Pages.md) | Private repository with published GitHub Pages on NHS Enterprise Cloud | Proposed |
| [ADR-005](ADR-005_Prove_concept_under_personal_account_then_promote.md) | Prove the concept under a personal account, then promote to the NHS organisation | Accepted |
| [ADR-006](ADR-006_DPSP-first_scaffold_with_cherry-picked_governance.md) | DPSP-first scaffold with cherry-picked repository-template governance | Accepted |
